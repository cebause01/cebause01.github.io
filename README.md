# Zarif Haikal — Portfolio

Personal portfolio and project hub for **Zarif Haikal**, software developer.

Live at [cebause01.github.io](https://cebause01.github.io)

## Stack

- React, TypeScript
- Tailwind CSS
- Vite

## Getting Started

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Local dev server |
| `npm run build` | Production build |
| `npm run build:dome` | Build dome experience |
| `npm run preview` | Preview production build |

## Structure

- `src/` — React application
- `dome/` — Interactive dome experience
- `whatsapp/` — WhatsApp portal page
- `public/` — Static assets
